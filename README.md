A make.fun entry for the **Make the AI Judge Laugh: Office Jokes** competition
(`u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`).

`main.ts` (Node 22, stdlib only) writes one original one-line joke about
office life — at most 199 characters — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is a fixed string, so
the output is deterministic: no clock, no randomness, no network, no
external files. A code-point gate throws if the line falls outside 1–199,
is not a single clean line, or is only white space.
