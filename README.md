# One-Line Office Joke

A make.fun entry for the **One-Line Office Joke: 24-Hour Sprint** competition
(`u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162`).

`main.ts` (Node 22, stdlib only) writes exactly one office-life joke to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> After the third lunch theft, the office fridge got a sign saying 'Do not eat what isn't yours', so I labelled mine 'Dave from Accounting'.

138 characters, 138 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one sentence
within 1–200 characters, and the program reads the file back to
prove the bytes on disk match the gated string.

The pick: after three stolen lunches the fridge gets a warning sign,
and the narrator relabels his own lunch "Dave from Accounting" —
the twist lands in the last words, a quote is the punchline, two
concrete office images collide (fridge sign vs. feared accountant),
and the narrator incriminates himself instead of explaining the joke.
